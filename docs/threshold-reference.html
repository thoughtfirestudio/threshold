Visual Reference · "What Good Looks Like"

The Threshold

A short exploration-puzzle adventure · Gameboy register · D-pad + A/B only
Native res: 160×144, scaled ×3
Forest palette:
Controls: D-pad move · A interact/confirm · B cancel/back
01THE WOODS — Act I

Muted, foggy, low-contrast. Top-down. The deer watches and bolts if you rush it. No HUD, no quest marker — the player learns to look. All paths funnel toward the cabin.

Atmosphere over information. Fog vignette at screen edges. Tiles dithered, never flat. The deer (top-right) is the first lesson: the world reacts to how you move. Semi-transparent D-pad + A/B always present.
02THE CABIN — the object & the choice

Amber, intimate, still. A single room. On the table: an unnamed artifact (pale bone bowl, a light turning over inside it). Walk up, press A, get the yes/no.

The interaction beat. Dialogue box is the classic bordered GB style: double border, type-on text, blinking ▼. The choice — Use it / Not yet — is the only "menu" in the game, reachable with just A/B.
03THE THRESHOLD — the warp

The bespoke transition. Amber light collapses to a single point, geometry blooms outward, the forest palette shatters. ~2 seconds. This is the hinge of the whole game — it must feel like the floor changing.

Spend the restraint budget here. Concentric rings, radial distortion, palette mid-shift (forest greens bleeding into hyperspace color). Player sprite dissolving into pixels at center.
04HYPERSPACE — entity encounter (Act III)

Everything inverts. High-saturation color, tiling/breathing geometry, the pixel grid misbehaving. Single-screen rooms, each holding one entity = one dialogue puzzle = one piece of the payload.

The payoff register. "The Weaver" sits at the center of a pattern that IS the room. Animated scrolling ground, floating forest-symbols recontextualized. Same dialogue box, but inverted palette. No combat — challenge is comprehension.
05THE RETURN — same map, re-lit

Wake in the cabin, walk back into the woods. Same forest map, one flag flipped (hasCrossed). The shrine bowl can be filled, the deer no longer bolts, carved stones now read as language, new paths open. The second pass is the real treasure hunt.

One boolean, whole new game. Built once, experienced twice. Symbols that were decoration in Shot 01 now glow and parse. This is the "hidden easter eggs" pleasure delivered structurally, not as scattered gimmicks.
